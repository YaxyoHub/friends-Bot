# PDF Maker Bot

This is a simple Telegram bot that generates PDF files from text.  
Users can send text to the bot, and the bot will convert that text into a PDF document and send it back.

## Features

- Convert text to PDF
- Fast PDF generation
- Easy to use
- Works directly inside Telegram
- Clean and simple PDF format

## Technologies Used

- Python
- Aiogram
- FPDF / FPDF2
- Telegram Bot API

## How It Works

1. User sends a message to the bot.
2. The bot receives the text.
3. The bot generates a PDF file using the provided text.
4. The generated PDF file is sent back to the user.
